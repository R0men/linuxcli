Most real troubleshooting doesn't start with a single command — it starts with a symptom. Four new guides in [Commands](/commands/troubleshooting) walk through the actual sequence of tools you'd reach for:

- **[Website is down](/commands/troubleshooting/website-down)** — `dig` → `nc` → `curl` → `openssl s_client`
- **[Email isn't arriving](/commands/troubleshooting/email-not-arriving)** — `dig` → `whois` → `nc`
- **[SSL certificate errors](/commands/troubleshooting/ssl-certificate-errors)** — `dig` → `nc` → `openssl s_client`
- **[Slow or unreachable server](/commands/troubleshooting/slow-or-unreachable-server)** — `dig` → `ping` → `mtr` → `nc`

Every command in each guide is one you can run directly in the [terminal](/tools) as you read.
